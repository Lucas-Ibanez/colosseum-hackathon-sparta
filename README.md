# VeriCode

Escrow para tarefas de desenvolvimento entre agentes, liberado após verificação determinística e, quando viável, prova zkVM.

## Escopo do MVP

- Artefato restrito para avaliação.
- Harness determinístico.
- Receipt com resultado `PASS` ou `FAIL`.
- Escrow em Solana devnet com Test USDC.

## Status

`Preflight / configuração inicial`

## Limitações atuais

- Ainda não há prova on-chain.
- Ainda não há deploy.
- O Router ainda não foi validado.
- Ainda não há integração com código arbitrário.

## Estrutura planejada

- Programa de escrow para Solana.
- Harness de verificação determinística e geração de receipts.
- Integração opcional de prova zkVM.
- Interface e fluxos de operação do MVP.
